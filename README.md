# [Equipe Safira]

> Do curso técnico de Desenvolvimento de Sistemas do Colégio Lindaura.

---

## 💻 Sobre o projeto
Nós 6 adolescentes do Ensino Médio Técnico em Desenvolvimento de Sistemas, e juntos formamos a Equipe Safira. Esse projeto foi feito no intuito de apresentar-nos para o público na 3ª Mostra dos Cursos Técnicos do Colégio Lindaura.
Esse evento é importante para a comunidade reconhecer a importância de se ter uma profissionalização, além de, claro, mostrar o quanto o nosso curso é legal (apesar de estressante às vezes) e convencer alunos a vir para nosso curso.

---

## 👾 Tecnologias Utilizadas
- **Estrutura e Semântica:** HTML5
- **Estilização e Layout:** CSS3
- **Lógica e DOM:** JavaScript
